## Фактически изменено

- Убраны здоровый tracker status/последнее наблюдение/сырые timestamps/reasons,
  coverage и gaps sections, повторные объяснения неполноты, легенда q и tutorial
  про14дней/scroll/sticky, служебные LOCAL/URI/privacy/fallback/revision пояснения,
  повторяющиеся пустые/обучающие карточки и developer year-layout prose.
  Для пустого/неполного значения остаётся компактное «Нет данных» или «Недостаточно
  данных». Known0/partial/unknown не объединены, Ready score/эмоции не пересчитываются.
- `UserNotices.kt` не рисует известные routine success (`SYNC_SNAPSHOT_COMPLETE`,
  `SHARING_SAVED` и т.п.) и не требует «Понятно». Важные ошибки остаются компактным
  баннером с закрытием; неизвестная ошибка также не скрывается. Текст берётся из
  безопасного user-facing code mapping, а не raw debug/hostname/исключения. Storage,
  login, conflicts, permission и необходимое новое consent остаются заметными.
- Server URL editor/save/change dialog полностью отсутствуют, скрытого developer
  диалога не добавлено. Ни hostname/port, ни URL в sync/share consent не выводятся.
  Connection state только читается для сохранённых account/login/sync guards.
  Ни одного production UI вызова ConfigureServer не осталось. Нынешние target,
  профиль, session, vault и account **не изменялись**.
- Сохранены явные Login/Logout/pending refresh, discoverability, tracking switch/
  Android permissions и manual sync. В здоровом состоянии нет повторного статуса
  «служба активна». При проблеме доступа есть короткое сообщение и переход в Android.
- Sync по-прежнему требует отдельный dialog, **unchecked** checkbox и кнопку send;
  согласие ограничено одним запуском, проверяется server/profile/account target,
  не переживает изменение target/не создаётся при входе. Упоминание передаваемых
  интервалов/перерывов оставлено именно в consent, не как ordinary diagnostics.
  Sharing сохраняет explicit dates/zone/absolute-set replacement/revoke disclosure
  и checkbox; authority/revision/ACL проверки не ослаблялись.
- Shorts actual остаётся исключительно read-only с дополнительным MANUAL-mode
  guard даже при ошибочном flag. **Кнопка изменения лимита есть всегда при
  `cell.canEditGoal`**, независимо от partial actual/score/наличия resolved goal.
  Никакой блокировки YouTube по лимиту нет. Поле лимита явно подписано «Минуты»:
  число ×60000 → raw duration_ms. Нулевой AT_MOST/overgoal/manual input не обрезаются.
  Неизменённый periodic decimal minute input возвращает исходный BigDecimal точно.
- Общий renderer duration_ms: `2 ч 3 мин 4 с`, нулевые части пропускаются,
  0→`0 с`, 0<value<1000ms→`<1 с`. Subsecond remainder только при выводе отбрасывается,
  raw precision и payload не меняются. Нет Long/Float overflow при больших decimal.
  Подписанный duration curve сохраняет знак; pages/manual minutes/plan_shares
  остаются собственными единицами, не преобразуются как milliseconds.
  Карточка, детали и дневные строки статистики используют один actual/goal helper.
- Shorts intervals сохранены: локальное `HH:mm:ss → HH:mm:ss` в zone выбранного дня,
  без `.SSS`/`Z`/technical quality. Дата добавляется при пересечении/выходе за
  выбранный день, год — при необходимости. Длительность — тем же h/min/s formatter.
  Скрытие gap rows не удаляет их из state/storage или sync.
- Сегодня выделено отдельной рамкой/marker, **не цветом q**: Today date selector
  имеет явную кнопку текущего дня, week/month headers — независимую рамку today
  и отдельную заливку/semantics selected. Marker работает и при unavailable cells.
- Заголовок «Настройки» — меньшая typography, maxLines1/без переноса. Profile area
  ограничена96dp в settings/details (160dp на основных экранах); длинное имя
  сокращается внутри своей области, не забирая ширину заголовка.
